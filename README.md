## 参数

如 Fastfetch 没有被添加进PATH或无法直接通过 `fastfetch` 命令调用。请使用 `--exe-path` 或 `-p` 参数来指定 Fastfetch 可执行文件的绝对路径

### 示例

```bash
fflp.exe -p "C:\Softwares\Fastfetch\fastfetch.exe"
```
